# Reset Code Generator

Утилита для автоматической генерации методов `Reset()` для структур Go.

## Описание

Генератор сканирует все пакеты проекта и для каждой структуры с комментарием `// generate:reset` создает метод `Reset()`, который сбрасывает все поля структуры к их нулевым значениям.

## Использование

### 1. Запуск генератора

```bash
go run ./cmd/reset/
```

или скомпилировать и запустить:

```bash
go build ./cmd/reset/
./reset
```

### 2. Добавление комментария к структуре

Добавьте комментарий `// generate:reset` перед определением структуры:

```go
// generate:reset
type MyStruct struct {
    ID    int
    Name  string
    Tags  []string
    Meta  map[string]string
}
```

### 3. Результат

Генератор создаст файл `reset.gen.go` в том же пакете:

```go
// Code generated by reset; DO NOT EDIT.

package mypackage

func (m *MyStruct) Reset() {
    if m == nil {
        return
    }
    m.ID = 0
    m.Name = ""
    m.Tags = m.Tags[:0]
    clear(m.Meta)
}
```

## Правила сброса полей

### Примитивные типы
Сбрасываются к нулевым значениям:
- `int`, `int8`, `int16`, `int32`, `int64` → `0`
- `uint`, `uint8`, `uint16`, `uint32`, `uint64` → `0`
- `float32`, `float64` → `0`
- `string` → `""`
- `bool` → `false`

### Указатели на примитивы
Если указатель не `nil`, разыменовывается и сбрасывается:
```go
if obj.fieldPtr != nil {
    *obj.fieldPtr = zeroValue
}
```

### Слайсы
Обрезаются по длине, но сохраняют capacity:
```go
obj.slice = obj.slice[:0]
```

### Мапы
Очищаются встроенной функцией `clear()`:
```go
clear(obj.mapField)
```

### Вложенные структуры
Если структура имеет метод `Reset()`, он вызывается:
```go
if resetter, ok := any(obj.field).(interface{ Reset() }); ok {
    resetter.Reset()
}
```

### Указатели на структуры
Проверяется на `nil` и вызывается `Reset()` если доступен:
```go
if obj.nested != nil {
    if resetter, ok := any(obj.nested).(interface{ Reset() }); ok {
        resetter.Reset()
    }
}
```

### Именованные типы из стандартной библиотеки
Сбрасываются к нулевым значениям типа:
```go
obj.timestamp = time.Time{}
```

## Примеры

### Пример 1: Простая структура

```go
// generate:reset
type User struct {
    ID    int64
    Name  string
    Email string
    Age   int
}
```

Сгенерированный метод:
```go
func (u *User) Reset() {
    if u == nil {
        return
    }
    u.ID = 0
    u.Name = ""
    u.Email = ""
    u.Age = 0
}
```

### Пример 2: Структура с коллекциями

```go
// generate:reset
type Metrics struct {
    Values   []float64
    Labels   []string
    Metadata map[string]string
}
```

Сгенерированный метод:
```go
func (m *Metrics) Reset() {
    if m == nil {
        return
    }
    m.Values = m.Values[:0]
    m.Labels = m.Labels[:0]
    clear(m.Metadata)
}
```

### Пример 3: Вложенные структуры

```go
// generate:reset
type Request struct {
    ID      string
    Payload []byte
    Meta    *Metadata
}

// generate:reset
type Metadata struct {
    Timestamp time.Time
    Headers   map[string]string
}
```

Сгенерированные методы будут корректно обрабатывать вложенность и вызывать `Reset()` для `Meta`.

## Технические детали

- Генератор использует пакеты `go/ast`, `go/parser` для разбора исходного кода
- Пропускает директории: `.git`, `vendor`, `testdata`, скрытые директории
- Игнорирует файлы: `*_test.go`, `*.gen.go`
- Автоматически добавляет необходимые импорты (например, `time`)
- Форматирует сгенерированный код через `go/format`

## Интеграция в CI/CD

Рекомендуется добавить проверку в CI, что все файлы `reset.gen.go` актуальны:

```bash
# Запустить генератор
go run ./cmd/reset/

# Проверить что нет изменений
git diff --exit-code '*.gen.go'
```

Или добавить в `go:generate` директиву в main пакет:

```go
//go:generate go run ./cmd/reset/
```
